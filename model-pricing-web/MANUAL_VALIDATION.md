# 浏览器人工验收路线

日期：2026-09-13。依据：当前路由、页面代码、README及VALIDATION记录。本文是操作指南，不是已执行的验收报告。

## 1. 准备与使用规则

- 打开 `http://127.0.0.1:5173/`，服务未启动时按README启动；端口以实际启动地址为准。
- 登录页选择账号所属门户；内部开发环境可通过“开发身份”选择人员。出现403先核对门户、身份和菜单权限，不要反复刷新。
- 当前没有真实登录，使用开发会话；所有业务仍为Axios + MSW。界面验收通过最多代表Frontend Ready，不代表数据库保存或生产权限已验证。
- **跨页面、跨身份的业务验证请在同一个标签页完成，使用菜单或页面刷新按钮，不按F5、不整页重载。** Mock业务数据保存在内存，整页刷新恢复样例；另一个标签页也不是共享数据库。
- 若需回到初始样例，可整页刷新，但此前创建的记录会丢失。记录主题或开发身份保存不等于业务持久化。
- 每次修改只跑相关路线；失败记一次就停，不反复点击、重试或遍历全部模块。按钮暂不可用先记录状态和原因。
- 下文“应”是验收标准；达不到就记录问题，不将未执行项标记通过。不要使用真实客户、供应商资料或敏感文件。

## 2. 建议先走的10分钟主路线

1. 供应商门户 → 新建报价：选择SKU组件、填写价格和时间，确认保存，记下报价编号。
2. 报价历史 → 同一编号详情 → 编辑草稿：修改价格，保存后重开详情核对。
3. 报价详情 → 提交审批；切换内部门户和“陈昊 · 采购审批”。
4. 供应商报价 → 搜索同一编号 → 详情 → 通过；应为APPROVED_PENDING，不能立即已生效。
5. 切回供应商 → 报价历史 → 查询同一编号；应显示相同状态及审批意见。
6. 切到内部“周婷 · 定价运营” → 成本管理：查询基线及供应商对比，只读，不要求审批后马上变化。
7. 价目表 → 新建价目表 → 填写基本信息、添加售价项 → 保存草稿 → 重开详情核对。

涉及全页重载持久化、成本自动重算或真正发布的部分，目前不能通过此路线验收。

## 3. 内部运营

### 3.1 工作台

身份：任一内部身份。地址：`/#/internal/workbench`。

路线：查看用户、指标和待办 → 点击一个快捷入口 → 切换内部身份 → 返回工作台。

预期：入口与当前权限一致，不显示无权限的业务入口；指标是开发样例，不能当真实经营数据。

### 3.2 模型查询与详情

身份：林悦 · 模型运营。地址：`/#/internal/models`。

路线：系列视图展开系列 → 切换SKU视图 → 搜索编码 → 按厂商/系列/状态筛选 → 查询 → 换页 → 重置 → 点击SKU打开详情 → 刷新档案。

预期：系列按系列分页，SKU按型号分页；搜索不存在的编码显示空结果，重置恢复数据。详情与所选SKU一致，展示能力、最大输出、币种、验证状态及下线日期；0不是空值，缺失能力显示未声明。协议、验证历史与退役申请明确标注暂定扩展，不伪造官方价/成本。

附加：先开一个模型，再开另一个，核对最终编码，旧响应不得覆盖新对象；此项只需尝试一次。

### 3.3 模型创建与编辑

路线：新建模型 → 选择厂商和所属系列 → 填唯一编码，例如 `manual-check-001` → 选择类型、币种、能力和最大输出 → 保存档案 → 确认 → 搜索该编码 → 编辑 → 修改能力/输出长度 → 保存 → 重开详情。

预期：创建为DRAFT；回显与输入一致；编辑不迁移厂商/系列、不直接改变生命周期。空编码、重复编码和负数应被明确拒绝，失败不增加记录。取消确认不保存。

### 3.4 批量提交验证与人工验证

路线：选中新建草稿 → 批量操作 → 提交待验证 → 查看逐项结果 → 查询待验证模型 → 人工验证 → 先留空说明尝试保存 → 填说明 → 保存验证记录 → 核对确认信息 → 确认。

预期：批量展示逐项失败而不是统一报成功；不能批量上架/退役。验证说明必填，1000字限制是Mock暂定约定；确认期间不可改输入或重复提交。Mock通过后为PURCHASABLE，不通过仍为PENDING_VERIFY；详情可查看验证历史，页面不直接改状态。

### 3.5 别名维护与合并边界

路线：模型 → 别名 → 输入唯一别名 `manual-alias-001` → 添加到当前模型 → 确认 → 关闭重开核对 → 移除 → 确认。再尝试重复别名。

预期：添加/移除有确认；重复、空白或超长别名失败，不破坏原值。若提示“已保存但查询失败”，重新查询，不重复提交。

合并路线：当前模型为来源 → 输入未占用别名 → 查重Top3 → 选择保留目标 → 核对来源/目标/别名 → 确认 → 打开目标核对别名。

边界：Mock只登记未占用别名，来源记录和状态不变，不代表真实SKU合并。来源编码通常会触发全局唯一冲突，这是待确认边界；不要通过改名宣称完成编码迁移。供应商回填及来源生命周期未实现。

### 3.6 模型上架与退役申请

上架身份：周婷 · 定价运营。路线：查询PURCHASABLE → 上架 → 核对编码和当前状态 → 确认 → 重新查询。预期：接口返回PUBLISHED；不能将其他状态模型直接上架。

退役身份：林悦 · 模型运营。路线：已上架模型 → 发起退役 → 加载退役影响分析 → 核对引用和替代建议 → 填日期及理由 → 提交 → 确认 → 查看申请单号。

预期：没报告不能提交；报告对应当前模型；加载失败可重试。早于/等于今天或不足演示通知期的日期被拒绝。通过路线可选 `2099-01-01`，仅作开发样例，不是真实计划。提交后等待定价运营第一审批，模型仍PUBLISHED，不应直接下线；重复申请应拒绝。

### 3.7 供应商报价审批

身份：陈昊 · 采购审批。地址：`/#/internal/supplier-quotes`。

路线：筛选待审批 → 查看详情 → 核对供应商、SKU和价格项 → 通过或驳回 → 填意见/原因 → 确认 → 重新查询。通过与驳回使用两张不同的报价单，避免重复改已处理单。

预期：通过仅APPROVED_PENDING；驳回为REJECTED并回显原因。同页再次操作已处理报价应被拒绝或入口消失。跨门户回显按第2节验证；成本自动生效不在当前验收范围。

提交保护：点击“通过整单”后，意见确认框应只出现一次，不能再切换报价或关闭原详情；取消不发送审批。驳回提交期间原因不可编辑，不能重复点击。确认信息对应原报价编号，不能因点击另一单而改变目标。

异常路线（有可控失败样例时选跑）：审批接口成功、随后详情/列表查询失败，应提示“审批已完成，重新查询，勿重复提交”；点“重新查询详情”只读取结果，不再次审批。仅断网不保证能命中这一时序，无法触发就标未覆盖。

### 3.8 成本与供应商档案（只读）

成本身份：陈昊或周婷。地址：`/#/internal/cost`。路线：搜索/筛选 → 查询 → 详情 → 核对完全成本、参数/汇率快照、主供应商和供应商价格对比。预期：只读，不由前端修改成本或选择最终主供。

供应商身份：林悦。地址：`/#/internal/suppliers`。路线：搜索 → 按合作/资质状态筛选 → 详情 → 查看脱敏主体、资质和供给范围。预期：只读，不要求新增、停用或审批资质。

### 3.9 价目表与定价策略

身份：周婷 · 定价运营。

价目表地址：`/#/internal/price-books`。路线：查询 → 详情 → 新建价目表 → 填基本信息 → 添加SKU组件与售价 → 保存草稿 → 重新查询 → 编辑草稿 → 保存 → 详情 → 提交审批。

预期：售价回显准确；非草稿不能原地编辑；低于floor的提示不是最终审批结论，以接口结果为准。提交不等于生效，不要求发布、回滚或后台激活功能。

策略地址：`/#/internal/pricing/policies`。路线：查询策略 → 详情 → 新建策略 → 选择目标毛利率或官方价锚定 → 保存草稿 → 编辑草稿后重开核对。预期：启用/停用版本只读，不要求完整模拟器。

### 3.10 客户与客户报价

身份：周婷。地址：`/#/internal/customers`。

路线：客户管理标签 → 搜索/筛选 → 详情查看当前价目表和合同 → 客户报价标签 → 新建报价草稿 → 填客户及价格项 → 保存 → 查询详情 → 编辑草稿 → 保存后核对。

预期：客户管理和报价同一业务入口；保存仍为DRAFT，不直接变正式报价或合同。客户档案本阶段不要求新增/编辑。

### 3.11 官方价格同步

身份：林悦查看采集/暂存；周婷参与定价审批。地址：`/#/internal/official-prices`，暂存可直接进入 `/#/internal/official-prices?tab=staging`。

路线：查看采集任务 → 暂存来源 → 核对来源和价格 → 生成变更单 → 查看变更单 → 按可用审批入口分级处理；需要定价审批时切换周婷继续。

预期：只有当前状态和权限允许的动作可操作；审批完成仅APPROVED（已批准待生效），不提供前端生效按钮。真实采集、定时激活及自动同步未联调。

### 3.12 告警与审计

告警身份：林悦/陈昊/周婷，处理各自权限范围。地址：`/#/internal/alerts`。路线：查看待处理 → 筛选 → 查看 → 确认并开始处理 → 标记已解决 → 填处理说明 → 确认已解决 → 查询状态。预期：状态由接口回显，只读身份没有处理入口。

审计身份：林悦或只读观察员。地址：`/#/internal/audit`。路线：搜索操作人/对象 → 筛选模块/结果/日期 → 查询 → 详情 → 查看请求标识、前后值及影响 → 导出当前筛选。预期：导出开发报告可打开；不要假设所有新业务操作已接入同一审计事件链，若无日志记录为待补事项。

### 3.13 财务、组织权限与系统对接（只读）

- 许宁 · 财务运营：`/#/internal/finance` → 查看月度汇率、客户授信/押金及结算条件；不要求锁汇、调授信或登记押金。
- 顾言 · 系统管理员：`/#/internal/org-permissions` → 查看组织树、角色、Portal、权限编码和字段限制；不要求配置或保存权限。
- 顾言：`/#/internal/integration` → 查看接口通道、同步任务、事件和MCP能力边界；不执行真实外部调用或任务重跑。

## 4. 供应商门户

身份：云桥科技 · 供应商。除跨门户联动外均在供应商门户完成。

### 4.1 首页与报价创建/编辑

首页：`/#/supplier/home` → 查看本主体指标与待办 → 点击报价入口。

新建：`/#/supplier/quotes/new` → 选择可报价SKU/组件 → 添加价格项 → 核对自动带出的币种、单位、税费和上次价格 → 填生效时间、结束时间、供应价 → 保存草稿 → 确认。

编辑：`/#/supplier/quotes` → 查看详情 → 编辑草稿 → 修改价格/时间 → 保存 → 重开详情。

预期：SKU口径来自选项，不靠手输；空价格、0、负数、超过8位小数、结束时间早于/等于生效时间应拒绝，失败保留输入且不增加记录。保存后仍DRAFT。已提交单无编辑入口，直接打开旧编辑地址也应拒绝。

补充边界（可选，不计入10分钟主路线）：准备两张草稿，从一张编辑地址切换到另一张，核对最终价格/时间属于后一张，旧请求不能覆盖。如果本地请求太快，无法验证慢响应顺序就记“未覆盖”，不要反复重试。失效/口径变化场景需要专门Mock样例：详情项保留旧币种/单位等，而选项接口已变化或移除该项；编辑应提示具体失效项并阻止保存，原价格不自动改写，移除并重新选择后才能继续。现有固定样例不保证能直接触发此场景，不要求业务人员改代码制造数据。

### 4.2 报价提交与跨门户结果

路线：报价历史 → 搜索编号 → 查看详情 → 提交审批 → 同标签页切换内部 → 按3.7审批 → 切回供应商查询同编号。

预期：当前Mock提交后为APPROVING；内部通过后APPROVED_PENDING，驳回后REJECTED。意见/原因可回显；供应商详情不含内部成本、毛利或内部审批按钮。不验证跨标签页实时推送。

保护路线：点击提交审批 → 确认框核对编号 → 尝试再次点击/关闭详情/编辑草稿，应被阻止 → 取消确认后仍可编辑。成功后查询失败应提示已提交、勿重复提交，并可“重新查询详情”。快速切换两张详情时只显示后一张报价，旧成功/失败响应不得覆盖；固定Mock太快时只记未覆盖，不反复试。

### 4.3 批量导入

地址：`/#/supplier/quotes/import`。

路线：下载CSV模板 → 用样例数据填写并保留列名 → 选择CSV文件 → 开始预检 → 查看逐行错误 → 修改原文件重新选择/预检 → 无错误时确认导入并生成草稿 → 报价历史核对。

预期：有错误不能确认导入；预检不生成正式报价；生成草稿后仍需提交审批。只测试小文件，不反复上传或验证真实附件存储。

### 4.4 新模型申请

地址：`/#/supplier/model-applications`。

路线：搜索/筛选历史 → 查看详情/驳回原因 → 新建申请 → 填所需字段 → 保存草稿 → 详情 → 提交内部审核。

预期：提交后SUBMITTED，不自动创建可采购/已发布模型；内部审核与模型入库未实现，不能要求在内部模型列表立即出现。

### 4.5 主体档案与资质

档案：`/#/supplier/profile` → 维护联系资料 → 修改联系/服务区域 → 保存 → 重新查看。预期：主体法定与结算信息只读，联系资料可回显；不要求主体变更申请。

资质：`/#/supplier/qualifications` → 提交资质材料 → 填资料并选择无敏感内容的样例文件 → 提交审核 → 查看进度。预期：不会直接审核通过；当前仅模拟文件信息，不代表真实文件上传或存储完成。

### 4.6 结算与对账（只读）

地址：`/#/supplier/reconciliation`。

路线：查询周期/状态 → 打开对账单 → 核对币种、金额与逐SKU明细。

预期：只读展示本主体开发样例；不要求确认对账、差异申诉、打款或结算完成，不将前端金额展示当作真实账务核算。

## 5. 权限、错误与页面框架

- 内部切换只读观察员 → 模型/报价等允许查看的页面：应无写按钮；不要用隐藏按钮代替后端安全验收。
- 切换不同Portal后，粘贴不属于该Portal的地址：应被阻止或引导正确入口。403记下当前身份与目标地址。
- 搜索不存在的编码 → 空结果 → 重置；每个实际查询页应能恢复正常结果。
- 可选错误测试：浏览器开发者工具将网络设为离线后，在已加载页面点刷新一次；若请求确实失败，应显示可理解错误并保留合理状态，恢复网络后重试一次。MSW下若没有触发错误，记为未覆盖，不据此宣称通过。
- 客户门户已实现Mock查询/详情，按第7节验收；不能据此声称真实客户接口、数据库或账务可用。
- 真实登录、401回登录、数据库持久化、后端字段物理剔除、行级权限、定时生效及真实结算均待真实环境联调。

## 6. 问题记录格式

新增草稿保护验收：价目表、客户报价、新模型申请分别点击保存 → 确认期间尝试修改输入或重复保存，应被锁定 → 取消应保留输入、不写入 → 再次确认保存后重开核对。金额输入Infinity或指数形式应拒绝；新模型资料URL输入`https://`或上下文负数应拒绝。写成功后刷新失败的专门时序样例尚未提供，无法触发记未覆盖，不通过反复点击制造结果。

每个失败记录：日期 / 身份 / 页面地址 / 操作步骤 / 预期 / 实际 / 截图（脱敏）/ 是否整页刷新。必要时补报价编号或模型编码，不记录Token、Cookie或真实业务资料。

结果只标：通过、失败、未执行、当前未实现。默认不勾选；发现问题后先保留页面，不反复试到“偶然成功”。验收记录可追加到VALIDATION.md或工作区已有问题记录，本文保持操作指南用途。

## 7. 客户门户操作路线

身份：左下角切换客户门户，当前开发主体为蓝海电商。所有页面为Mock，仍使用同一个标签页，不整页刷新来验证业务保存。

1. `/#/customer/home`：查看主体名称、报价/合同/通知数量、账户概况 → 点击各快捷入口。预期：进入对应页面，不再是静态框架；余额/授信/押金按CNY展示，不与USD报价合计。
2. `/#/customer/price-book`：搜索编号/名称 → 状态筛选 → 查询 → 查看详情。预期：可查看组件售价、币种/单位和生效时间，显示Mock等级价来源；不展示floor、成本、毛利或内部审批字段，不承诺合同优先取价已实现。
3. `/#/customer/quotes`：查询报价 → 搜索 `CQ-BLUE-DEMO-ACCEPT` → 查看详情 → 接受报价 → 核对编号和Mock限制 → 取消一次（不写入）→ 再次确认 → 重开详情。预期：接受时间回显、接受按钮消失；报价仍FORMAL，不自动创建合同。已签合同报价只读；客户看不到内部草稿，也不应看到灯塔教育等其他客户记录。
4. 接受失败/时序边界：有效期由Mock后端检查，页面只看canAccept；未生效、过期、已接受或非正式报价不允许接受。固定主体样例不包含所有状态，缺少样例记未覆盖，不通过改URL/反复试制造成功。确认和请求期间不可切换详情/关闭弹窗/重复提交；成功后查询失败应提示已接受、勿重复提交，并可重新查询详情。
5. `/#/customer/contracts`：查询合同 → 查看详情 → 核对时间范围和逐组件价格快照。预期：只读；快照是明确的开发样例，与接受动作不自动联动，不支持签约/取消/续约。
6. `/#/customer/billing`：查看账户 → 按待结清/已结清筛选 → 查看账单 → 核对周期、总额与明细。预期：全部金额字符串展示、币种明确；无充值、付款、开票或申诉按钮，账务样例不代表真实计费完成。
7. `/#/customer/notifications`：查询通知 → 查看价格调整/退役正文。预期：内容明确样例及实际规则待确认；不伪造已读操作或计数，不因查看通知改变价格/模型状态。
8. 通用：搜索不存在的名称 → 空结果 → 重置；每页刷新/详情重查可使用。页码可点击时换页；样例不足一页不代表已验证第二页。网络/慢请求异常按第5节选跑，无法触发记未覆盖。

当前客户报价与内部查询复用同一份Mock报价记录，但内部新建仍是DRAFT、不会对客展示；正式化/发布尚未开放。客户接受只记录确认回执，不改变报价状态；内部详情已显示接受时间，完整合同流程待确认。

## 8. 供应商申请审核与客户回执联动（Mock）

使用同一个浏览器标签，通过现有开发身份切换进行验证；不要整页刷新（内存Mock会重置）。

1. 供应商身份 → 资质资料页 → 提交新资质，使用正确的时间范围和附件文件信息 → 查看提交记录。切换模型运营 → `/#/internal/suppliers` → 上方“供应商资质审核” → 查询 / 刷新 → 搜索新材料 → 详情 / 审核 → 驳回不填原因应被阻止 → 填写原因并确认。切回供应商，重新查询资质，核对REJECTED及相同原因。附件仍只显示文件信息，无真实上传存储。
2. 供应商身份 → 新模型申请 → 创建并提交申请。切换模型运营 → `/#/internal/models` → 上方“供应商新模型申请审核” → 查询申请并打开详情 → 核对厂商、编码、类型、能力、资料URL、申请原因 → 通过并确认 → 核对处理记录。切回供应商重新查询，核对APPROVED与审核意见；内部模型列表不得自动出现新模型。入库仍需现有创建草稿流程。
3. 待审核记录分别验证确认取消、通过、驳回；处理后重新打开，不再有审核按钮。查询不存在的名称应为空；切换状态、分页和刷新。只读身份不应看到审核入口，直接请求审核也应403。模拟超时后未修改内容重试应复用幂等Key；改变意见后不应复用旧Key。后两项为可选网络测试，未执行记未覆盖。
4. 客户身份 → `/#/customer/quotes` → `CQ-BLUE-DEMO-ACCEPT` → 接受并确认 → 核对接受时间。切换定价运营 → `/#/internal/customers` → 客户报价 → 搜索同一编号 → 详情 → 核对“客户已接受”及接受时间；报价仍FORMAL，不产生合同。尚未接受的报价详情应显示“客户尚未接受”。
5. 价目表 → 草稿保存 → 提交审批 → 状态APPROVING。页面说明双人审批规则尚缺，不应出现单人通过、驳回或立即生效按钮。第三批审批处理未完成，不能据此验收发布闭环。

## 9. 续报、供给约束、客户套价/克隆、手工官方价（2026-09-14，Mock）

本节是待执行路线。连续使用同一标签切换身份，不整页刷新。

1. 供应商续报：采购审批身份 → `/#/internal/supplier-quotes` → 云桥科技待审批报价 → 驳回并填原因。供应商身份 → `/#/supplier/quotes` → 同一报价详情 → “续报 / 修订新版本”。应带出原价格、清空旧时间；重新选择生效/结束时间，结束早于或等于生效应被阻止。保存后同编号新ID、版本递增、状态DRAFT，旧单仍REJECTED。重复续报版本仍唯一递增，不能原地覆盖旧单。
2. 供给约束：新建或续报表单 → 填最大并发20、RPM200、TPM100000、实际上下文128000、兼容说明。分别输入负数、小数、0应被阻止。保存→详情→编辑草稿核对回填→提交审批→切采购审批身份查询同一单，核对约束一致。留空应表示未声明，不表示无限制；逐SKU不同限制尚未实现。
3. 客户套价：定价运营 → `/#/internal/customers` → 客户报价 → 新建 → 选择蓝海电商 → “套用客户当前价目表” → 自动带出价格及参考/floor → 移除不需要的组件、调整价格、填名称/原因/截止时间 → 保存DRAFT → 重开查看。当前采用明确GOLD开发样例，不是真实等级价。选择灯塔教育等尚无可用价目表的客户，带价应提示不可用，不能返回另一等级价格；换客户必须清空旧价格项。
4. 客户克隆：打开现有FORMAL或CONTRACT报价 → “克隆为新报价草稿” → 名称带新草稿标记、时间/原因重新填写、客户不能更换 → 修改价格并保存。新单DRAFT、旧单价格和状态不变；不得复制客户接受时间或创建合同。取消克隆后再编辑其他草稿，不能误走克隆保存。
5. 官方价格手工录入：模型运营 → `/#/internal/official-prices?tab=staging` → “手工录入官方价格” → 选择GPT 4.1，币种/单位及基准自动显示 → 输入价保持2、输出价改9 → 填HTTP/HTTPS来源与依据 → 保存到暂存区。来源暂未核验，confidence=0；查询新暂存记录 → 采用人工来源并填写核对依据 → 生成PRICE_UP变更，输出前值8/后值9，双人审批。不应因为只调整输出而走降价单签，也不会立即生效。两价均不变的暂存确认应409、保留PENDING；无效链接、指数金额、超过8位小数应被拒绝。
6. 以上操作均选跑取消确认、失败反馈和重新查询；慢请求/超时复用Key按第8节选跑。业务层自动测试不代表本节浏览器步骤已执行。
7. 成本参数：定价运营 → `/#/internal/cost` → 任一SKU详情 → “维护SKU成本参数” → 修改损耗率为4、通道费为1.5、填写理由 → 确认保存。重开同一详情，核对配置修订号、修改人/时间及新值；上方已计算完全成本和成本组成快照应保持原值，不宣称已重算。输入负数、超过100、空理由应被阻止；采购审批/只读身份可查看配置但无编辑入口。税项、供应商覆盖、选主锁定尚未实现。
8. 供应商倍率：供应商 → 新建报价 → 选择GPT 4.1输入组件（Mock官方基准2）→ 倍率模式 → 填0.9，供应价应自动为1.8；改为绝对价手填1.7，应只显示约0.85倍。添加输出组件后应用整单0.9倍，先取消一次应不改价格，再确认应逐组件换算。保存/重开/编辑/提交后切内部采购审批，核对倍率与基准版本回显。Mini输入官方基准0.4、倍率1.12345678的精确价格超8位小数，应提示降低精度，不能自动舍入提交。USD汇率档位、缓存维度及自动跟随版本不在本次验收内。
9. 导入模板：供应商 → `/#/supplier/quotes/import` → 选择历史报价SKU或全部可报价SKU → 用名称/编码筛选 → 下载模板，核对本主体预填SKU、价格及明日时间；修改后上传→预检→确认草稿。换文件应清除旧预检；读取/预检/确认期间不能换文件或重复提交，确认取消后可继续操作。当前仍9列绝对价CSV，不声称Excel、倍率或官方价只读列完成。
